# EMOS 上传插件

将媒体文件上传到 EMOS（Emby 资源站上传分发系统）的 MoviePilot V2 插件。

## 功能特性

- 🔄 **入库自动上传**：监听 MoviePilot 入库完成事件，自动上传源文件到 EMOS
- 🎯 **服务器端识别**：通过 EMOS 接口自动识别文件，匹配剧集信息
- 📊 **版本对比**：上传前检查已有资源版本（分辨率 + 文件大小），相同版本跳过
- ⚡ **分片并发**：多分片并发上传，最大化吞吐
- 📝 **上传历史**：记录最近 50 条上传记录
- 🔔 **通知集成**：上传结果通过 MoviePilot 通知渠道推送

## 配置说明

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| 启用插件 | 开启/关闭插件 | 关闭 |
| 上传模式 | ask=询问确认 / silent=自动上传 | ask |
| Token 文件路径 | EMOS token 文件路径 | /opt/data/creds/emos_token |
| 目标分片数 | 上传时的分片数量 | 24 |
| 并发数 | 并发上传线程数 | 16 |

## 上传模式

插件支持两种模式，在配置页「上传模式」中切换：

### ask（询问模式，默认）

入库后自动识别并汇报，**等待用户确认后才上传**：

1. MoviePilot 入库完成 → 触发 `TransferComplete`
2. 调用 EMOS 识别接口，获取剧集信息（剧名 / 集数 / 大小 / 分辨率）
3. 检查并对比 EMOS 已有资源版本
4. 通过通知发送「待确认上传」报告，包含：剧名 / 文件 / 大小 / 已有版本 / 版本对比结论
5. 等待用户确认后才执行上传

版本对比结论：
- 无资源 → 提示「将作为首个版本上传」
- 版本不同 → 提示「版本不同，可上传补充」
- 版本相同 → 自动跳过并提示「无需重复」

**确认命令**（通过 MoviePilot 远程命令发送）：

| 命令 | 说明 |
|------|------|
| `/emos_confirm 传` | 上传全部待确认文件 |
| `/emos_confirm 传 2` | 只上传编号 2 的文件 |
| `/emos_confirm 不传 2` | 跳过编号 2 的文件 |
| `/emos_status` | 查看状态和待确认列表 |

> 每个待确认文件都有独立编号（如 [1]、[2]），可单独或批量确认。

### silent（静默模式）

入库后自动识别并对比版本，**无需确认直接上传**，不打扰用户。

## 版本对比规则

只比较两项：

| 比较项 | 规则 |
|--------|------|
| 分辨率 | 完全匹配（2160P / 1080P / 720P / 480P） |
| 文件大小 | 差异 ≤ 5% 视为相同 |

两项都匹配 → 判定为相同版本，跳过上传。

## 上传流程

1. MoviePilot 入库完成 → 触发 `TransferComplete` 事件
2. 获取源文件路径（`transferinfo.src`）
3. 调用 EMOS 识别接口，获取剧集信息
4. 检查 EMOS 已有资源版本
5. 版本对比：无资源/版本不同 → 可上传；版本相同 → 跳过
6. 分片并发上传到 EMOS 存储
7. 完成合并，保存记录
8. 发送通知

## API 接口

| 接口 | 说明 |
|------|------|
| `GET /api/v1/plugin/EmosUpload/status` | 获取状态、待确认列表和上传历史 |
| `GET /api/v1/plugin/EmosUpload/pending` | 获取待确认上传列表 |

## 远程命令

- `/emos_status` - 查看上传状态和待确认列表
- `/emos_confirm 传 [编号]` - 确认上传
- `/emos_confirm 不传 [编号]` - 跳过上传
