# EMOS 上传插件

将媒体文件上传到 EMOS（Emby 资源站上传分发系统）的 MoviePilot V2 插件。

## 功能特性

- 🔄 **自动上传**：监听 MoviePilot 入库完成事件，自动上传到 EMOS
- 🎯 **服务器端识别**：通过 EMOS 接口自动识别文件，匹配剧集信息
- 📊 **版本对比**：上传前检查已有资源版本，避免重复上传
- ⚡ **分片并发**：支持分片并发上传，最大化吞吐（约 13 MB/s）
- 🔔 **通知集成**：上传结果通过 MoviePilot 通知渠道推送
- 📝 **上传历史**：记录最近 50 条上传历史

## 配置说明

### 基本配置

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| 启用插件 | 开启/关闭插件 | 关闭 |
| 上传模式 | ask=询问确认 / silent=自动上传 | ask |
| Token 文件路径 | EMOS token 文件路径 | /opt/data/creds/emos_token |

### 上传配置

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| 目标分片数 | 上传时的分片数量 | 24 |
| 并发数 | 并发上传线程数 | 16 |

## 上传流程

1. MoviePilot 入库完成 → 触发 `TransferComplete` 事件
2. 调用 EMOS 识别接口，获取剧集信息
3. 检查 EMOS 已有资源版本
4. 版本对比：无资源/版本不同 → 上传；版本相同 → 跳过
5. 分片并发上传到 R2 存储
6. 完成合并，保存记录
7. 发送通知
