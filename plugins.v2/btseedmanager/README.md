# MoviePilot BT 种子管家插件

MoviePilot V2 插件：只处理 **BT 站点（公开站）**下载的种子——按种子单独限速、做种时长到点只暂停；**PT 站种子一律不碰**，也**不修改下载器的全局限速设置**。

本实现基于 V2 插件基类：`app.plugins._PluginBase` / `app.log` / `app.helper.downloader`，站点与下载历史分别走 `app.db.site_oper.SiteOper` 与 `app.db.downloadhistory_oper.DownloadHistoryOper`。

## 为什么需要

PT 站有分享率考核，做种要尽量久、速度要尽量给；BT 站（公开站）反过来——做种的人多、长期挂着只是白占上传带宽和队列。而下载器的限速是**全局**的，为 BT 限速就会连 PT 一起限掉。

本插件用下载器的**单种子接口**（`change_torrent` / `stop_torrents`）逐种子处理，只挑出 BT 站点来的种子：

| 能力 | 做法 | 影响范围 |
| --- | --- | --- |
| 上传/下载限速 | 每个 BT 种子单独设 `upload_limit` / `download_limit`（KB/s） | 只影响该种子，不动全局 |
| 做种时长上限 | 下载完成且做种超过设定小时后**只暂停**该种子 | 不删任务、不删文件 |
| PT 保护 | 判定为 PT 的种子完全跳过 | 一个接口都不调用 |

## BT / PT 怎么判定

按下面的顺序判定，命中即停：

| 顺序 | 依据 | 结论 |
| --- | --- | --- |
| 1 | 下载历史里的站点名，命中「站点管理」中 `public = 1` 的站点 | BT |
| 2 | 下载历史里的站点名，命中 PT 站点 | PT，跳过 |
| 3 | 没有下载历史（或站点已删除）时看 tracker 域名：命中 PT 站点域名或其子域（如 `t.ubits.club` 属于 `ubits.club`） | PT，跳过 |
| 4 | tracker 域名命中「额外 BT 站点/域名」白名单 | BT |
| 5 | 其余情况：公开 tracker（如 `anidex.moe`、`tr.bangumi.moe`）或没有 tracker 的纯 DHT 种子 | BT |

判定不准时有两个补救开关：**额外 BT 站点/域名**（把误判成 PT 的站点拉回 BT）和**额外 PT 站点/域名**（把误判成 BT 的站点踢出）。两者都填站名或域名，逗号分隔。

## 工作原理

1. 按检查间隔遍历选定的下载器（qBittorrent / Transmission），取全部种子
2. 批量读下载历史，拿到每个种子的来源站点名；没有历史的再查 tracker 域名
3. 判定为 PT 的种子直接跳过；命中「排除标签」的种子也跳过
4. 对 BT 种子调用**单种子**限速接口；目标值与上一轮相同就跳过，避免反复调用
5. 开启了做种时长上限时：只处理**已下载完成**（进度 100%）的种子，已做种秒数达到上限就调用 `stop_torrents` 暂停
6. 暂停过的种子记入清单，可在详情页看到，也可以用 `/resume` 一键恢复（恢复后进入豁免清单，之后不再自动暂停）

## 配置说明

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| 启用插件 | 关 | 开启后按间隔自动执行 |
| 试运行（只打印不执行） | 关 | 只把计划写进日志与详情页，不调用任何修改接口 |
| 立即运行一次 | 关 | 保存配置后马上跑一轮 |
| 发送通知 | 关 | 有限速、暂停或失败时发通知 |
| 下载器 | 空 | 留空表示全部已启用的 qBittorrent / Transmission |
| 通知渠道 | 空 | 留空不发通知 |
| 上传限速（KB/s） | 0 | 0 表示不限制（不调用上传限速） |
| 下载限速（KB/s） | 0 | 0 表示不限制 |
| 做种时长上限（小时） | 0 | 0 表示不启用；可填小数；到点只暂停 |
| 检查间隔（分钟） | 10 | 定时检查间隔 |
| 排除标签 | 空 | 逗号分隔，命中标签的种子一律不动（例如 PT 站点专用标签） |
| 额外 BT 站点/域名 | 空 | 逗号分隔，站名或域名都行 |
| 额外 PT 站点/域名（豁免） | 空 | 逗号分隔，站名或域名都行 |

## 插件接口

| 接口 | 说明 |
| --- | --- |
| `POST /run` | 立即执行一轮 |
| `GET /status` | 最近一次执行摘要、已暂停清单、豁免清单、已设置的限速 |
| `POST /resume` | 恢复本插件暂停过的种子，并加入豁免清单 |
| `POST /reset` | 清空豁免清单 |

## 注意事项

- **只暂停，不删除**：做种时长到点只调用 `stop_torrents`，任务和文件都留着；想删种请用其它插件或手动处理
- **不做种就不计时**：只有进度 100% 的种子才参与做种时长判断，下载中的种子不受影响
- **每种子限速不是全局限速**：限速只写在该种子上，新加的种子下一轮会被补上，旧的全局设置不受影响
- **Transmission 的做种时长按完成时间算**：Transmission 接口里没有「已做种秒数」字段，插件用 `doneDate` 到当前时间的差值近似；qBittorrent 直接用 `seeding_time`
- **建议先开试运行**：第一轮用试运行看清 BT / PT 判定是否符合预期，尤其是只用公开 tracker 的 PT 站种子（会被判成 BT）
- **tracker 结果有缓存**：种子的 tracker 列表缓存 24 小时，换 tracker 后最多一天内仍按旧结果判定
