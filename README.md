# MoviePilot QB 上传限速插件

这是一个只支持 MoviePilot V2 插件市场结构的分享率限速插件。下载器下拉支持选择 MoviePilot 中已配置并启用的 qBittorrent / Transmission 下载器。

## 功能

- 检测所选下载器中的种子分享率（分享率 = 上传量 / 下载量）
- 种子分享率达到设定阈值（正整数）后，自动将该种子的上传速度限制为指定值（KB/s）
- 支持启用后定时检测并持续应用限速，防止被其他插件或手动操作覆盖
- 支持立即运行一次
- 支持按站点筛选：勾选站点后，仅对所选站点下载的种子执行分享率限速（留空则对所有种子生效）
- 限速通知：新限速的种子逐条发送通知（可多选通知渠道），内容为「站点所下的种子已限速多少KB/s」，站点、种子、速度加粗显示
- 停用或卸载插件时自动恢复已限速种子的上传速度（不限速）

## 安装

将本仓库配置到 MoviePilot V2 插件市场后，在插件市场中安装「QB上传限速」。

仓库目录结构：

    plugins.v2/qbuploadlimiter/__init__.py
    package.v2.json
    icons/Qbittorrent_A.png

## 配置说明

- 启用插件：启用后立即检测一次，并按配置间隔定时检测。
- 立即运行一次：保存后 3 秒执行一次，不要求保持启用；首次点击会自动发送一次测试通知，之后重复点击不再发送。
- 分享率阈值：种子的分享率 = 上传量 / 下载量；当种子分享率 ≥ 阈值（正整数）时限制其上传速度。
- 上传限速（KB/s）：达到阈值后的种子上传速度上限，默认 2000；0 表示取消限速（恢复默认）。
- 定时检测间隔（秒）：默认 30 秒，最短 10 秒，建议设置 30 秒以上。用于持续监控种子分享率，达到阈值后自动限速，并防止限速被其他插件或手动操作覆盖后失效。
- 下载器：请选择 MoviePilot 系统设置中已配置并启用的 qBittorrent 或 Transmission 下载器。
- 站点：可多选 MoviePilot 系统设置中已配置并启用的站点；留空表示对所有种子生效，勾选后仅对所选站点下载的种子进行限速。站点识别优先使用 MoviePilot 下载历史中的站点记录，其次通过种子 tracker 域名识别，再匹配种子标签/分类中的站点名。
- 发送通知：可多选 MoviePilot 系统设置中已配置并启用的通知渠道；留空表示不发送通知。新限速种子会逐条发送「站点所下的种子已限速多少KB/s」通知，点击通知直达插件详情页。插件通知不受 MoviePilot 通知渠道的「通知场景」开关限制，勾选的渠道必定收到。
