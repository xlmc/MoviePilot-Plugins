### [QB分享率限速](https://github.com/xlmc/MoviePilot-Plugins/tree/main/plugins.v2/qbuploadlimiter)
  当 qBittorrent 中已下载的种子分享率达到设定阈值时，自动将该种子的上传速度限制为指定值（KB/s），支持多下载器、定时检测和停用恢复。
