# MoviePilot QB 上传限速插件

这是一个只支持 MoviePilot V2 插件市场结构的分享率限速插件。下载器下拉支持选择 MoviePilot 中已配置并启用的 qBittorrent / Transmission 下载器。

## 功能

- 检测所选下载器中的种子分享率（分享率 = 上传量 / 下载量）
- 种子分享率达到设定阈值（正整数）后，自动将该种子的上传速度限制为指定值（KB/s）
- 支持启用后定时检测并持续应用限速，防止被其他插件或手动操作覆盖
- 支持立即运行一次
- 支持按站点筛选：勾选站点后，仅对所选站点下载的种子执行分享率限速（留空则对所有种子生效）
- 支持监控超时取消：种子下载完成后若在设定秒数内上传速度达不到限速值，或限速后持续限速/上传速度低于限速值 80% 达到设定秒数时，自动取消监控，不再设置限速
- 限速通知：新限速的种子逐条发送通知（可多选通知渠道），内容为「站点所下的种子已限速多少KB/s」，站点、种子、速度加粗显示
- 停用或卸载插件时自动恢复已限速种子的上传速度（不限速）

## 安装

将本仓库配置到 MoviePilot V2 插件市场后，在插件市场中安装「QB上传限速」。

仓库目录结构：

    plugins.v2/qbuploadlimiter/__init__.py
    package.v2.json
    icons/Qbittorrent_A.png

## 配置说明

- 启用插件：启用后立即检测一次，并按配置间隔定时检测。
- 立即运行一次：保存后 3 秒执行一次，不要求保持启用；首次点击会自动发送一次测试通知，之后重复点击不再发送。
- 分享率阈值：种子的分享率 = 上传量 / 下载量；当种子分享率 ≥ 阈值（正整数）时限制其上传速度。
- 上传限速（KB/s）：达到阈值后的种子上传速度上限，默认 2000；0 表示取消限速（恢复默认）。
- 定时检测间隔（秒）：默认 30 秒，最短 10 秒，建议设置 30 秒以上。用于持续监控种子分享率，达到阈值后自动限速，并防止限速被其他插件或手动操作覆盖后失效。
- 下载完成后监控超时（秒）：种子下载完成后，若在设定秒数内上传速度始终达不到限速值，则取消监控（不再设置限速）；0 表示不启用。
- 限速后取消监控超时（秒）：种子被限速后，持续限速或上传速度低于限速值 80% 达到设定秒数时，取消监控（不再设置限速）；0 表示不启用。
- 下载器：请选择 MoviePilot 系统设置中已配置并启用的 qBittorrent 或 Transmission 下载器。
- 站点：可多选 MoviePilot 系统设置中已配置并启用的站点；留空表示对所有种子生效，勾选后仅对所选站点下载的种子进行限速。站点识别优先使用 MoviePilot 下载历史中的站点记录，其次通过种子 tracker 域名识别，再匹配种子标签/分类中的站点名。
- 发送通知：可多选 MoviePilot 系统设置中已配置并启用的通知渠道；留空表示不发送通知。新限速种子会逐条发送「站点所下的种子已限速多少KB/s」通知，点击通知直达插件详情页。插件通知不受 MoviePilot 通知渠道的「通知场景」开关限制，勾选的渠道必定收到。

## 源文件联动清理

MoviePilot V2 插件，专为**手动清理下载目录**场景设计：手动删除源文件（下载目录中的原始媒体文件）后，插件自动联动清理媒体库中对应的**硬链接文件**、**刮削文件**（元数据、图片、字幕）与**转移记录**，保持媒体库与下载目录状态一致，避免残留失效文件。

适用场景：
- 手动删除下载目录中的源文件，媒体库中的硬链接文件自动被清理
- 联动清理被删除文件同名的刮削文件（.nfo、图片、字幕等元数据）
- 联动删除对应的转移记录，避免历史记录残留
- 支持空目录清理、延迟删除（防止媒体重整理导致误删）与通知

设计参考 [DzAvril/MoviePilot-Plugins](https://github.com/DzAvril/MoviePilot-Plugins) 的清理媒体文件插件（removelink），本插件为独立实现，聚焦硬链接联动清理场景。

### 功能

- 监控源目录与媒体库目录，记录每个文件的 `(dev, inode)` 以识别硬链接关系
- 源文件删除后，自动删除媒体库中所有指向同一文件实体的硬链接文件
- 联动清理被删除文件同名的刮削文件（.nfo/.jpg/.srt 等，后缀可自定义）
- 联动删除转移记录（按目标路径或源路径匹配）
- 自动清理只剩刮削文件或完全为空的目录
- 可选联动删除种子（需安装插件[下载器助手]并打开监听源文件事件）
- 可选延迟删除（默认 30 秒），防止媒体重整理/重命名导致的误删
- 支持排除目录、过滤关键字、发送通知

### 安装

将本仓库配置为 MoviePilot V2 插件市场后，在插件市场中安装「源文件联动清理」。

仓库目录结构：

    plugins.v2/scrapefileclean/__init__.py
    package.v2.json
    icons/clean.png

### 配置说明

- **启用插件**：开启后启动目录监控并全量建立文件状态。
- **监控目录**：每行一个目录。源目录（下载目录）和媒体库目录（硬链接目录）都需要添加，
  插件才能识别源文件与硬链接的对应关系。
- **不删除目录**：命中其中的文件不会被删除。如需实现「删除硬链接时不删除源文件」，
  可把源文件目录配置到这里。
- **过滤关键字**：路径包含关键字的文件不处理。
- **清理刮削文件**：删除媒体文件时联动清理同名的 .nfo、图片、字幕等元数据文件。
- **自定义刮削文件后缀**：每行或逗号分隔，会与内置后缀一起参与清理。
- **删除转移记录**：删除文件时清理对应的转移记录。
- **联动删除种子**：需安装插件[下载器助手]并打开监听源文件事件。
- **延迟删除**：删除事件进入队列，等待指定时间后再次校验再执行，防止误删。
- **发送通知**：清理完成后发送站点消息通知。

### 注意事项

- 清理刮削文件会删除相关的 .nfo、.jpg 等元数据文件，请谨慎开启。
- 插件不会自动删除不在监控目录中的文件；删除硬链接时如需保留源文件，请把源目录
  加入「不删除目录」。
